# Buvley — премиальный лендинг (Rhana)

Одностраничный лендинг с анимированным градиентным фоном, частицами на canvas, анимациями при скролле, параллаксом и интерактивной инфографикой состава.

## Запуск

Откройте `index.html` локально или поднимите статический сервер:

```bash
cd /workspace/buvley-landing
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Кастомизация
- Изображения поместите в `assets/images/` (`product-hero.svg`, `product-bottle.svg`, `before.svg`, `after.svg`, `logo-rhana.svg`).
- Цвета и типографика настраиваются в `styles.css` в блоке `:root`.
- Хуки отправки формы замените в `script.js` на реальную интеграцию (CRM/API).
